*geass.txt* AI inline completions for Neovim.

==============================================================================
INTRODUCTION                                    *geass*

geass.nvim provides ghost-text code completions from a local LLM using
the fill-in-the-middle technique.

Setup                                    *geass-setup*

  require("geass").setup({...})

See the README for full option reference.

==============================================================================
MAPPINGS                                        *geass-mappings*

<Plug>(geass-trigger)             *geass-key-trigger*
<Plug>(geass-accept)              *geass-key-accept*
<Plug>(geass-dismiss)             *geass-key-dismiss*

===============================================================================
COMMANDS                                         *geass-commands*

:Geass                  *geass-:Geass*
                        Toggle inline completions on/off.
                        Completes to the subcommands below.

:Geass toggle           *geass-:Geass-toggle*
                        Flip the enabled state.

:Geass on               *geass-:Geass-on*
                        Enable completions.

:Geass off              *geass-:Geass-off*
                        Disable completions. Cancels any in-flight request
                        and clears the current ghost-text preview.

The `enabled` option (default `true`) controls the initial state at
startup; see |geass-setup|.
